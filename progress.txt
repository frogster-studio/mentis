## Item 2 — Search word finds a Catalog word by start or equality without final s, accent-blind — DONE
- Module apps/admin/src/features/curation/search-words.ts: readQueryWords(query) → deduped folded words ([] for "?"/blanks); findQueryWords(queryWords, text) → one WordFind[] per query word ({ start, end, whole }, span in the original text).
- Fold per original character (NFD, strip \p{M}, lowercase, œ→oe, æ→ae), so spans map back to the original string with no offset table; a lone combining mark (text typed pre-decomposed) extends its word's span.
- whole = equal once a final s is dropped from each (a start covering the whole word is the same case); find = whole || item word startsWith query word.
- Per-query-word lists (not a boolean) so searchCatalog can AND query words across a Question's fields and count whole finds; deduped query words keep "che che" from double-counting.
